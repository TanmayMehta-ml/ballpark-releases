# BallPark: download

**BallPark** is a guesstimate trainer for consulting interviews, built around India. One question a day, a research team that gives you three clues, a streak, a shop and a Learn section.

## Try it in your browser
Open **https://ballpark.mehtatanmay9211.workers.dev** on any phone or computer. No install needed.

## Install on Android
1. Open the **[latest release](../../releases/latest)** on your phone.
2. Download **BallPark.apk** (about 21 MB). It works on almost every phone made in the last few years.
   Only if the install says the app is not compatible, download **BallPark-32bit.apk** instead.
3. Open the file. If Android asks, allow installs from this source ("Install unknown apps"), then tap **Install**.

Direct link to the newest version: `https://github.com/TanmayMehta-ml/ballpark-releases/releases/latest/download/BallPark.apk`

**Coming from an older version (1.x)?** Uninstall it first. Version 2 is a rebuilt app signed with a new key, so Android will not install it over the old one. Your old progress does not carry over; version 2 starts fresh.

Your progress is stored on your phone only. There is no login and no account.

## What is new in version 2
A rebuilt app with smoother animation and a native feel: confetti and a flame that grows with your streak, animated avatars, borders and banners, soft music and sound effects, and daily reminders at about 3 pm and 10 pm that you can switch off in Settings.

## Notes
- This app is not on the Play Store, so Android shows a one-time warning when you install it.
- This repository only hosts the download files. The source code is private.
